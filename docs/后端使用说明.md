## 1. 环境准备

### 1.1 安装依赖

```powershell
cd Pokemon\backend
pip install -r requirements.txt
```

### 1.2 配置环境变量

复制并编辑 `.env` 文件（在 `Pokemon\` 根目录）：

```powershell
Copy-Item .env.example .env
```

用记事本打开编辑：

```powershell
notepad .env
```

填写以下配置：

```env
# Neo4j Aura 云数据库
NEO4J_URI=neo4j+s://98695523.databases.neo4j.io
NEO4J_USER=98695523
NEO4J_PASSWORD=你的密码

# 通义千问 LLM
DASHSCOPE_API_KEY=sk-你的API密钥
LLM_MODEL=qwen-plus
```

## 3. API 接口

### 3.1 主问答接口 `POST /api/chat`

**最核心的接口**，输入自然语言问题，返回查询结果和自然语言回答。

**请求**：
```json
{
  "question": "皮卡丘有什么属性？"
}
```

**响应**：
```json
{
  "answer": "皮卡丘是电属性的宝可梦。",
  "cypher": "MATCH (p:Pokemon {name: \"pikachu\"})-[:HAS_TYPE]->(t:Type) RETURN t.name",
  "data": [
    {"t.name": "electric"}
  ]
}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `answer` | string | LLM 生成的自然语言回答 |
| `cypher` | string | LLM 生成的 Cypher 查询（可展示给用户） |
| `data` | array | Neo4j 原始查询结果 |

**测试示例**（PowerShell）：

```powershell
# 健康检查
Invoke-RestMethod http://localhost:8000/api/health

# 属性查询
Invoke-RestMethod -Method Post -Uri http://localhost:8000/api/chat `
  -ContentType "application/json" `
  -Body '{"question": "皮卡丘有什么属性？"}'

# 属性克制
Invoke-RestMethod -Method Post -Uri http://localhost:8000/api/chat `
  -ContentType "application/json" `
  -Body '{"question": "火属性克制哪些属性？"}'

# 招式查询
Invoke-RestMethod -Method Post -Uri http://localhost:8000/api/chat `
  -ContentType "application/json" `
  -Body '{"question": "皮卡丘会什么招式？"}'
```

> **提示**：也可以用浏览器打开 http://localhost:8000/docs 直接在 Swagger UI 中测试所有接口。

### 3.2 直接查询接口 `POST /api/query`

**调试用**，直接执行 Cypher 查询。

**请求**：
```json
{
  "cypher": "MATCH (p:Pokemon) RETURN p.name LIMIT 5",
  "parameters": {}
}
```

**测试**（PowerShell）：
```powershell
Invoke-RestMethod -Method Post -Uri http://localhost:8000/api/query `
  -ContentType "application/json" `
  -Body '{"cypher": "MATCH (p:Pokemon) RETURN p.name LIMIT 5", "parameters": {}}'
```

**响应**：
```json
{
  "data": [
    {"p.name": "bulbasaur"},
    {"p.name": "ivysaur"},
    {"p.name": "venusaur"},
    {"p.name": "charmander"},
    {"p.name": "charmeleon"}
  ]
}
```

## 6. Neo4j 连接方式

当前使用 **HTTP API**（端口 443）连接 Neo4j Aura，而非 Bolt 协议（端口 7687）。

**原因**：当前网络环境对 7687 端口的 SSL 握手有拦截，导致 Bolt 协议无法建立连接。HTTP API 通过 443 端口（标准 HTTPS）通信，不受影响。

**连接配置**（`config.py`）：
```python
NEO4J_HTTP_URL = "https://98695523.databases.neo4j.io/db/98695523/query/v2"
NEO4J_USER = "98695523"
NEO4J_PASSWORD = "从.env读取"
```

如果将来网络环境改善（如在实验室或家中），可以切换回 Bolt 协议：
1. 将 `neo4j_service.py` 中的 HTTP 实现改回 `neo4j` Python driver
2. 确认 `neo4j+s://98695523.databases.neo4j.io:7687` 可连通

## 7. LLM 配置

当前使用通义千问 API（OpenAI 兼容接口）：

```python
DASHSCOPE_BASE_URL = "https://dashscope.aliyuncs.com/compatible-mode/v1"
LLM_MODEL = "qwen-plus"
```

**注意事项**：
- 模型名称在 `.env` 中配置，可改为其他通义千问模型
- 思考模型（如 `qwen3.5-flash`）会在返回内容中包含 `<think>` 标签，代码已自动清理
- Cypher 生成使用 `temperature=0.1`（低随机性），回答生成使用 `0.3`

## 8. 常见问题

### Q: 启动报错 `ImportError: cannot import name 'ServiceUnavailable'`

Neo4j 5.20 中 `ServiceUnavailable` 在 `neo4j.exceptions` 模块，不在 `neo4j` 根模块。当前代码已修正。

### Q: 查询返回空数据

检查是否使用了正确的**关系名称**：
- 属性克制关系是 `DAMAGE_TO`（旧关系名已废弃）
- 数据库中**没有** `EVOLVES_TO` / `EVOLVES_FROM` 进化关系

### Q: LLM 生成的 Cypher 执行失败

可能原因：
1. Pokemon 名称必须用英文小写：`"pikachu"` 不是 `"Pikachu"` 或 `"皮卡丘"`
2. LLM 使用了数据库中不存在的关系名
3. LLM 使用了数据库中不存在的属性名

### Q: `check_env.py` 在 Windows 下报编码错误

`check_env.py` 使用 ASCII 字符（`[OK]`、`[FAIL]`），已兼容 Windows GBK 编码。

### Q: PowerShell 中 `curl` 命令报错

PowerShell 中 `curl` 是 `Invoke-WebRequest` 的别名，行为与 Linux curl 不同。请使用：
- `Invoke-RestMethod` 调用 API（推荐，自动解析 JSON）
- `curl.exe` 调用真正的 curl（如果已安装）
- 浏览器打开 http://localhost:8000/docs 使用 Swagger UI（最简单）
